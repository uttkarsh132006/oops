# OOPs in C++ 💻

This repository contains the C++ programs and code that I wrote while learning and practicing Object-Oriented Programming (OOPs).

The purpose of this repository is to understand the fundamental concepts of OOPs through practical implementation and regular coding practice.

## 📚 Topics Covered

- Classes and Objects
- Constructors
- Destructors
- Access Specifiers
- Encapsulation
- Abstraction
- Inheritance
- Polymorphism
- Function Overloading
- Operator Overloading
- Friend Functions
- Static Members
- `this` Pointer
- Getters and Setters
- Copy Constructor
- Other OOP Practice Programs
